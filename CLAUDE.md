# HarnessBuddy

## What This Project Does

HarnessBuddy is a Python CLI tool that automates preparation of C/C++ libraries for
fuzzing. Given a repository URL, it:

1. Detects the build system (CMake, Meson, Autotools, Makefile).
2. Builds the library locally to validate it and collect install artifacts.
3. Probes harness compilation to discover transitive linker dependencies.
4. Generates two output directories:
   - `local/` — a standalone dev scaffold (`setup.sh`, `build_library.sh`,
     `build_harness.sh`, `harness_src/`)
   - `oss-fuzz/` — a complete OSS-Fuzz project (`project.yaml`, `Dockerfile`,
     `build.sh`, `build_library.sh`, `compile_harnesses.sh`, `harness_source/`)

When a static build fails, an optional LLM agent (`--agent claude|codex`) attempts
to repair the build script.

## Source Map

```
src/harnessbuddy/
  cli.py                        # CLI entry point and top-level pipeline
  core/
    repos.py                    # repo ingestion (URL clone, local path)
    subprocesses.py             # streaming subprocess runner
    paths.py                    # state dir and workspace paths
  library_builder/
    models.py                   # shared dataclasses (AnalysisResult, BuildExplorationResult, ...)
    analysis.py                 # static build-system and language detection
    exploration.py              # host-side build execution and artifact validation
    scripts.py                  # per-build-system build_library.sh templates
    agents.py                   # LLM agent fallback orchestration
    harness_explorer.py         # harness compilation probe (--whole-archive dep discovery)
    local/generation.py         # local output scaffold generation
    oss_fuzz/generation.py      # OSS-Fuzz project generation
```

## Key Commands

```bash
uv run harnessbuddy generate <REPO_URL>                # full pipeline
uv run harnessbuddy generate <REPO_URL> --agent claude # with LLM fallback
uv run pytest -q                                       # run tests
uv run ruff check                                      # lint
uv run ty check                                        # type check
```

## Development Standards

- Runtime: Python 3.13, managed with `uv`.
- Lint: `ruff check` — zero warnings required.
- Types: `ty check` — zero errors required.
- Tests: `pytest -q` from repo root.
- All shell scripts generated by this tool must use `set -euo pipefail`.
- No relative imports (`..` paths) — absolute imports only.
- See `plans/python_code_standards.md` for full standards.
